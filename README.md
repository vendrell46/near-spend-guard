# near-spend-guard

An on-chain spending guard for AI agents on NEAR: the contract holds the funds, the agent calls it through a function-call key, and the contract enforces per-payment caps, a rolling daily cap, receiver allowlists, payload-bound human approvals and a kill switch. Testnet only.

Work in progress, built at NEAR HACKATHON, 1–14 Nov 2026.
